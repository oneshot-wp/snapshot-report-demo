# Check the numbers before you automate the report

If your weekly content report includes repeated cumulative snapshots, adding every row can count the same activity twice. This Python sample keeps the latest snapshot for each platform and content ID, then reports the cumulative performance of content published in the selected week.

[View the recorded synthetic cases](https://oneshot-wp.github.io/snapshot-report-demo/) · [Inspect the source and tests](https://github.com/oneshot-wp/snapshot-report-demo)

## What the sample demonstrates

- Latest-snapshot selection rather than summing duplicate cumulative records.
- Separate treatment of an observed zero and a missing metric.
- Rejection of conflicting snapshots with the same timestamp.
- Markdown reports and traceable JSON output from a standardized JSON array.

The web page shows three fixed synthetic cases generated by the Python program. It does not run new customer files online. These are self-built demonstrations, not client results. The report measures cumulative performance as of the available snapshots, not activity newly earned during the reporting week.
